# Apex Markets

Apex Markets is an F1-inspired interactive web project designed to bring the excitement, strategy, and technical brilliance of Formula 1 into a digital experience.

The website combines an engaging interface with interactive elements, custom animations, and dedicated sections exploring F1 concepts such as tyre strategies, pit stops, racing circuits, and driver performance.

### Key Features

- **Interactive UI & Animations:** Custom hover effects, animated components, interactive cards, and engaging user interactions that make exploring the website more immersive.
- **Podium Prediction Prototype:** A weather-based prediction prototype that uses predefined conditions and programmed rules to suggest potential podium outcomes. It is a demonstration of conditional logic, not a trained predictive algorithm.

### Tech Stack
- HTML5
- CSS3
- JavaScript

### Project Objective
To explore front-end development, interactive web design, JavaScript logic, and the application of programming concepts through the world of Formula 1.
